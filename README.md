# veloso.dev — Portfólio pessoal

Portfólio responsivo feito com HTML, CSS e JavaScript. A identidade visual usa verde oliva e off-white, com opção de alternar entre português e inglês.

## Como visualizar
Abra o arquivo `index.html` em um navegador. É necessário estar conectado à internet para carregar as fontes do Google Fonts; o restante do site funciona localmente.

## Publicar
1. Crie um repositório público no GitHub.
2. Envie os quatro arquivos deste projeto para a raiz do repositório.
3. Na Vercel, importe o repositório. Para este projeto estático, não é necessário configurar build command; a raiz do projeto é a pasta padrão.
